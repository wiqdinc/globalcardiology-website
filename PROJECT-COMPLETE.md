## 🔧 Customization Made Easy

### Change Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --primary-blue: #1e5ba8;
    /* Update to your preferred color */
}
```

### Add New Page
1. Copy any HTML file
2. Update content
3. Add navigation link in all pages

### Update Images
Replace files in `assets/images/`
No code changes needed!
